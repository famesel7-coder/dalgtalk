# DOLG TALK Казань 2026 — презентации спикеров

Рабочий репозиторий для стилизации готовых презентаций спикеров под корпоративный шаблон конференции.

## Задача

- сохранять содержание и логику исходных презентаций;
- аккуратно приводить слайды к фирменному стилю и сетке;
- не перегружать слайды декоративными решениями;
- не добавлять анимации без отдельного запроса;
- сохранять редактируемость текста, таблиц, графиков и основных элементов.

## Структура

- `assets/` — корпоративный шаблон и общие ресурсы;
- `docs/` — правила оформления, источники и рабочий процесс;
- `incoming/` — входящие драфты спикеров, по отдельной папке на каждого спикера;
- `deliverables/` — готовые проверенные презентации.

## Именование

- входящий файл: `incoming/<speaker>/<speaker>_draft_v01.pptx`;
- рабочий файл: `incoming/<speaker>/<speaker>_styled_v01.pptx`;
- финал: `deliverables/<speaker>/<speaker>_final.pptx`.

## Источник визуального стиля

Основной источник — корпоративный шаблон DOLG TALK Казань 2026. Презентации прошлой конференции используются только как референсы по композиционным приёмам и подаче контента.
