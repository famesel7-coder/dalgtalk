# Рабочий процесс

1. Сохранить исходный драфт без изменений.
2. Проверить формат, количество слайдов, мастер-слайды, шрифты и внешние связи.
3. Для каждого слайда выбрать ближайший тип из корпоративного шаблона.
4. Перенести контент с минимально необходимой переработкой композиции.
5. Сохранить исходные данные, смысл, порядок и редактируемость элементов.
6. Проверить переносы строк, переполнение, контраст, выравнивания, номера слайдов и логотипы.
7. Отрендерить все слайды и провести визуальную проверку каждого.
8. Сохранить финальную версию в `deliverables/<speaker>/`.

## Приоритеты

1. Точность контента.
2. Соответствие корпоративному шаблону.
3. Читаемость на экране конференции.
4. Аккуратность и единообразие.
5. Скорость обработки без лишнего редизайна.
